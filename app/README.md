# InteraX Frontend (`app/`)

Next.js / React web application providing interfaces for both patients and clinicians.

## Modules & Views

- **Patient Interface:**
  - Photo upload for handwritten medication lists and pill packaging.
  - Review digitized medication preview before submission.
  - Ephemeral, time-limited PIN generation for anonymous transfer.
- **Clinician Interface:**
  - PIN code entry to securely load an anonymous patient regimen.
  - Interactive medication table editor (edit dosage, frequency, route, oncology regimens).
  - Visual drug-drug interaction alerts and severity indicators.

## Tech Stack
- Next.js (React)
- Tailwind CSS / UI components
