# InteraX Experiments (`experiments/`)

Prototyping workspace for evaluating models, prompts, and datasets during the hackathon.

## Purpose

- Test optical character recognition (OCR) and vision-language models on handwritten prescription notes and pillbox packaging.
- Benchmark prompt engineering strategies for structured JSON extraction of medication regimens.
- Validate drug interaction databases and test contraindication detection against challenge sample datasets.
- Notebooks, exploratory scripts, and evaluation benchmarks.
